# Simple Calculator 🧮

A clean and modern web-based calculator built with HTML, CSS, and JavaScript. Perfect for quick calculations with an intuitive user interface.

## Features ✨

- ➕ **Basic Arithmetic Operations**: Addition, subtraction, multiplication, and division
- 🔄 **Clear Button**: Reset the calculator instantly
- ⌫ **Delete Button**: Remove the last digit
- 🎨 **Modern UI**: Beautiful gradient background with smooth animations
- 📱 **Responsive Design**: Works seamlessly on desktop and mobile devices
- ✓ **Decimal Support**: Handle decimal numbers with precision
- 🛡️ **Error Handling**: Prevents division by zero and multiple decimal points

## Demo 🎯

You can use this calculator directly by opening the `index.html` file in your web browser.
